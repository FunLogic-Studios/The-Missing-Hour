# Security Policy

## Supported Versions

Security issues are addressed for actively supported releases.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities before they have been reviewed.

Report security issues privately to the project maintainers through the contact method provided by the FunLogic Studios organization.

When reporting an issue, include:

* Description of the vulnerability
* Steps to reproduce
* Affected version
* Expected behavior
* Actual behavior
* Any relevant screenshots or logs

Please do not include passwords, private credentials, personal information, or other sensitive information.

## Scope

This policy applies to the publicly distributed The Missing Hour application and its official distribution infrastructure.

Gameplay bugs and ordinary application issues should be reported through GitHub Issues instead.
