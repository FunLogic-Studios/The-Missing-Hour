# Support

Need help with **The Missing Hour**?

## Installation Problems

If the game does not install or launch:

* Confirm that you downloaded the latest release.
* Confirm that you are using Windows.
* Restart the installation process.
* Check existing GitHub Issues for known problems.

## Gameplay Problems

For gameplay bugs, missing evidence, broken interactions, audio problems, or incorrect case behavior, open a GitHub Issue.

Include:

* Game version
* Description of the problem
* Steps to reproduce it
* Screenshots where useful

## Feature Requests

Feature requests and gameplay ideas can also be submitted through GitHub Issues.

## Case Spoilers

Please avoid revealing solutions, culprits, or major discoveries in public issue titles.

Use spoiler warnings when discussing case content.

## Contact

For matters that cannot be handled through GitHub Issues, contact the project maintainers through the official FunLogic Studios channels.
