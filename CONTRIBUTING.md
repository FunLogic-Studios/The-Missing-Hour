# Contributing to The Missing Hour

Thank you for your interest in **The Missing Hour**.

This repository is primarily used for game releases, documentation, player feedback, and issue tracking.

The game's development source code is not publicly available.

## Reporting Problems

If you encounter a problem while playing:

1. Check whether the issue has already been reported.
2. Open a new issue if it has not.
3. Clearly describe what happened.
4. Include your game version.
5. Include your Windows version where relevant.
6. Provide steps that reproduce the problem.

Screenshots or recordings are helpful when reporting visual or gameplay issues.

## Suggestions

Gameplay ideas and improvements are welcome through GitHub Issues.

Please explain:

* What you would change
* Why you think it would improve the game
* How it would affect the player experience

## Pull Requests

Pull requests modifying the game's private development code are not accepted through this repository.

Documentation improvements and other explicitly permitted repository changes may be considered.

## Spoilers

When discussing cases, suspects, evidence, or solutions, clearly mark major spoilers.

Do not reveal case solutions in issue titles.

Thank you for helping improve The Missing Hour.
