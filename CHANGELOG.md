## Versioning

The Missing Hour follows semantic versioning:

```text
MAJOR.MINOR.PATCH
```

Example:

```text
1.0.0
```

* **MAJOR** — Major game changes or incompatible changes
* **MINOR** — New gameplay/features
* **PATCH** — Bug fixes and minor corrections
